# Автономний торговий робот (працює без Claude)

> «Навіть коли у клода закінчиться ліміт api сам торгує на бінансі автономно,
> відкриває, закриває позиції без дозволів додаткових» — 28.11.2026

Коли закінчується ліміт Claude, Claude не працює взагалі, і заплановані перевірки
не запускаються. Тому торгівлю веде окрема програма
`omnis/strategies/autotrader.py`. Вона запускається на **вашому** комп'ютері або
на невеликому сервері і працює з **вашим** ключем Binance. Claude для неї не
потрібен.

Стратегія та сама, що й зараз, і код рушія той самий:

- монети Binance Alpha;
- не більше 5 позицій, плече 5x;
- стоп за 2 ATR, ризик 4% капіталу на угоду, тейк 2R;
- перенос стопу в беззбиток на +1R;
- вихід за 10-свічковим каналом;
- нових входів немає, якщо капітал менший за $220.

Програма відкриває і закриває позиції сама, без жодних підтверджень.

## Що робить кожні 30 хвилин (о :02 і :32 за UTC, тобто о :02 і :32 за Києвом)

1. Читає баланс, позиції, стопи й тейки, 4-годинні свічки.
2. Прибирає залишкові ордери на монетах, де позиції вже немає.
3. Переносить стоп у беззбиток, коли позиція в плюсі на 1R.
4. Якщо в позиції немає стопу, ставить його негайно. Якщо немає тейку, ставить тейк.
5. Закриває позиції за сигналом виходу і знімає їхні стопи та тейки.
6. Відкриває нові позиції за сигналом. Стоп ставить одразу, тейк — від реальної
   ціни входу. Якщо стоп не ставиться, позицію закриває негайно.

Вона ніколи не перевищує 5 позицій і плече 5x. Вона не торгує монетами поза
списком і не чіпає спот та гаманець. Вона ніколи нічого не переказує і не
виводить. Перекладання прибутку на спот лишається за Claude, бо для цього
потрібен дозвіл на перекази, якого ключ робота мати не повинен.

## Швидкий старт на Windows (комп'ютер працює цілодобово)

1. **Python.** Встановіть з https://www.python.org/downloads/. На першому екрані
   встановлювача обов'язково поставте галочку **«Add python.exe to PATH»**.
2. **Код.** Відкрийте
   https://github.com/Kucherenko22051991/Kucherenko22051991/tree/claude/blissful-archimedes-g1q2e9,
   натисніть **Code → Download ZIP** і розпакуйте архів, наприклад у `C:\omnis`.
3. **Ключ Binance.** Створіть його, як описано нижче в розділі «Ключ Binance».
4. Двічі клацніть **`1_vvesty_kluch.bat`** і вставте ключ і секрет. Під час
   введення символи не показуються, так і має бути. Робот одразу перевірить
   зв'язок і покаже баланс та позиції. Нічого не змінює.
5. Двічі клацніть **`3_avtozapusk.bat`**. Відтепер робот стартуватиме сам після
   кожного вмикання комп'ютера і входу у Windows. Цей файл також вимикає сон
   комп'ютера.
6. Двічі клацніть **`2_zapustyty_robota.bat`**, щоб запустити робота вперше вже
   зараз. Вікно можна згорнути, але не закривати. Якщо робот зупиниться через
   помилку, він сам перезапуститься за хвилину.

Якщо комп'ютер вимкнувся, просто увімкніть його і увійдіть у Windows. Робот
запуститься сам. Поки комп'ютер вимкнений, позиції захищені стопами й тейками на
біржі.

Щоб прибрати автозапуск, натисніть Win+R, введіть `shell:startup` і видаліть
файл `omnis_robot.bat`.

## Налаштування (один раз)

**1. Ключ Binance.** Створіть його в тому самому субакаунті, де йде торгівля:
Керування API → Створити API.

- Увімкніть **тільки** «Enable Futures» (торгівля ф'ючерсами).
- **НЕ вмикайте** виведення коштів (Withdrawals) і універсальні перекази (Universal Transfer).
- Увімкніть «Restrict access to trusted IPs only» і вкажіть IP комп'ютера або
  сервера, де працюватиме робот. Свою IP можна дізнатися на сайті 2ip.ua.
  Якщо домашня IP змінюється, ключ перестане працювати. Тоді додайте нову IP або
  не ставте обмеження: без дозволу на виведення ключ однаково не може вивести
  кошти, але з обмеженням безпечніше.
- Ключ нікому не надсилайте і не вставляйте в чат.

**2. Python 3.10 або новіший.** Для Windows: python.org → Download, при
встановленні поставте галочку «Add to PATH». Додаткові бібліотеки не потрібні.

**3. Код.** Скачайте репозиторій (GitHub → Code → Download ZIP) і розпакуйте.

**4. Файл `.env`.** Створіть його в корені папки репозиторію, поруч із цим файлом:

```
BINANCE_API_KEY=ваш_ключ
BINANCE_API_SECRET=ваш_секрет
```

Файл `.env` ніколи не потрапляє в репозиторій, бо він у `.gitignore`.

## Запуск

Відкрийте термінал у папці репозиторію.

```bash
python -m omnis.strategies.autotrader --check
```

Ця команда тільки перевіряє ключ і зв'язок і показує баланс, позиції, стопи й
тейки. Нічого не змінює.

```bash
python -m omnis.strategies.autotrader
```

Пробний прохід: показує, що робот **зробив би** зараз. Ордерів не ставить.

```bash
python -m omnis.strategies.autotrader --live --loop
```

Бойовий режим: торгує кожні 30 хвилин, доки вікно відкрите.

- Комп'ютер має бути увімкнений і не засинати. Найнадійніше запускати робота на
  невеликому сервері (VPS, приблизно $5 на місяць), який працює цілодобово.
- На сервері з Linux запускайте робота через `tmux` або `systemd`, щоб він
  працював і після відключення.

**Пауза нових входів:** створіть порожній файл `omnis/logs/PAUSE`. Робот і далі
стежить за відкритими позиціями (стопи, тейки, виходи), але нових не відкриває.
Щоб продовжити, видаліть цей файл.

**Журнал дій:** `omnis/logs/autotrader.jsonl`.

## Разом із Claude

Робот і Claude можуть працювати одночасно. Робот запускається о :02 і :32,
Claude — о :05 і :35, обидва дивляться на реальний стан біржі, тому дублів не
буде.

Коли ліміт Claude закінчується, робот продовжує торгувати сам. Коли Claude
повертається, він звіряє все з біржею і продовжує звіти.

Навіть якщо не працює ні робот, ні Claude, кожна позиція захищена стопом і тейком
прямо на біржі. Binance закриє її сам.

## Ризики

Прибуток не гарантований: стратегія може приносити і збитки, до 4% капіталу на
кожну угоду. Робот протестований на імітації біржі. Його перший бойовий запуск
бажано подивитися наживо.
